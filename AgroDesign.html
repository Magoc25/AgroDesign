💾 Presets de Experimento
📖 Como importar em softwares estatísticos

Exporte os dados como CSV (separador decimal configurável) e importe no software desejado.

🔵 R (agricolae / ExpDes.pt)
Use o Script R gerado pelo botão acima — ele já tem ANOVA, Tukey e verificação de pressupostos prontos para o seu delineamento.

Pacotes necessários: agricolae (DIC/DBC/DQL/Fatorial), ExpDes.pt (parcelas subdivididas).
🟠 SAS (PROC GLM / PROC MIXED)
Use o Script SAS gerado acima. Ele usa PROC IMPORT para ler o CSV e PROC GLM para a ANOVA.

Para split-plot, substitua PROC GLM por PROC MIXED com o statement RANDOM adequado.
🟡 Python (pingouin / scipy)
Use o Script Python gerado acima. Depende de: pandas, pingouin, scipy.
Instale com: pip install pingouin
🟢 ASSISTAT
1. Exporte o CSV e abra no Excel (ou Calc)
2. Copie a tabela de dados (a partir da linha 6, sem cabeçalho)
3. No ASSISTAT: Arquivo → Colar dados
4. Defina o delineamento e as variáveis na interface
🟢 Sisvar (UFLA)
1. Exporte o CSV
2. No Sisvar: Arquivo → Importar → CSV
3. Indique que o cabeçalho começa na linha 6 (pula metadados)
4. Mapeie Bloco, Tratamento e variável(is) de resposta
🟢 AgroEstat / Genes
Abra o CSV no Excel, selecione apenas as colunas de interesse (sem as linhas de metadados) e cole diretamente na planilha de entrada do software. Separe tratamentos e blocos conforme solicitado pelo programa.
