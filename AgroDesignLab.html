📖 Como analisar em outros softwares

Exporte os dados pela aba Coleta (CSV ou XLSX) e importe no software desejado.

🔵 R
Use o botão ⬇ R — o script é gerado para o modo ativo:
• CRD/RCBD — aov() + Tukey (agricolae)
• Dose-Resposta — curva 4PL e IC₅₀ (drc)
• Checkerboard — cálculo de FICI + heatmap
🟠 SAS
Use o botão ⬇ SAS:
• CRD/RCBD — PROC GLM + MEANS/TUKEY
• Dose-Resposta — PROC NLIN (4PL)
• Checkerboard — DATA step para FICI
🟡 Python
Use o botão ⬇ Python:
• CRD/RCBD — pingouin ANOVA + Tukey
• Dose-Resposta — scipy.optimize.curve_fit (4PL) + matplotlib
• Checkerboard — seaborn heatmap + FICI

Instalar: pip install pandas pingouin scipy seaborn matplotlib
🟣 GraphPad Prism
1. Exporte o CSV (ajuste Dec se necessário)
2. Prism → New Table → XY (dose-resposta) ou Grouped (ANOVA)
3. Cole colunas de Concentração e Valor por composto
4. Para 4PL: Analyze → Nonlinear regression → Inhibitor vs. response — Variable slope
🟢 Excel / LibreOffice
1. Use ⬇ XLSX para abrir direto no Excel
2. Tabela dinâmica para resumos por tratamento
3. Dose-resposta: gráfico de dispersão → linha de tendência (polinomial como aproximação)
